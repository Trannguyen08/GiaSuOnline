# API Reference

## Auth
- `POST /api/auth/register/`
- `POST /api/auth/login/`
- `POST /api/auth/refresh/`
- `GET /api/auth/google/`

## Users
- `GET /api/users/me/`
- `PATCH /api/users/me/`

## Tutors
- `GET /api/tutors/`
- `GET /api/tutors/{id}/`
- `GET /api/tutors/search/`

## Bookings
- `POST /api/bookings/`
- `GET /api/bookings/`
- `PATCH /api/bookings/{id}/`

## Reviews
- `POST /api/reviews/`
- `GET /api/tutors/{id}/reviews/`
